# Онлайн-практика: продуктовая аналитика в финтехе

**Автор:** Кирилл Федяров  
**Курс:** Продакт-менеджмент в финтехе  
**Период:** Июль – Август 2026

---

## Описание проекта

В рамках онлайн-практики был разработан продуктовый концепт «Умный кошелек» — фича для мобильного банковского приложения, помогающая студентам контролировать ежедневные траты.

---

## Выполненные задачи

1. Сегментация аудитории и определение болей пользователей
2. Генерация 5 идей финтех-продуктов и выбор одной для проработки
3. Проведение глубинных интервью с целевой аудиторией (2 респондента)
4. Формулировка гипотез и выбор методов их проверки
5. Проектирование пользовательского сценария и создание прототипа в Figma
6. Проведение коридорного теста и юзабилити-тестирования (3 респондента)
7. Определение North Star Metric и метрик по воронке AARRR
8. Оформление финальной питч-концепции продукта

---

## Результаты

- Прототип в Figma, прошедший юзабилити-тестирование
- Сформулированные гипотезы с планами проверки
- Система метрик для оценки успеха продукта
- Готовая питч-концепция для презентации стейкхолдерам
